FAQ

Frequently Asked Questions

Is VoterConnect an official government website?

No. VoterConnect is a student Community Engagement Project. It provides an easy interface to access official election information.

Which area is this project designed for?

The project is designed as a voter-information initiative for the Manchar, Pune area.

Where does the election information come from?

The website directs users to official Election Commission of India and Chief Electoral Officer, Maharashtra services.

Can I use this website on my phone?

Yes. The website is designed to work on smartphones, tablets and desktop computers.

What should I do if information changes?

Always follow the latest information published by the official election authorities.
